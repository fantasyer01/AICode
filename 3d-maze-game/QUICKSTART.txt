# QUICK START GUIDE - 3D Maze Explorer

## FOR USERS: How to Run

Unfortunately, you need to build from source since libraries aren't included.

### Step 1: Download Libraries (15 minutes)
1. Open `LIBRARIES_SETUP.txt`
2. Download GLFW, GLAD, and GLM from the provided links
3. Follow the setup instructions to place them in `lib/` folder
4. Copy `glad.c` from GLAD download to `src/glad.c`

### Step 2: Install Build Tools (if not already installed)
1. Download CMake: https://cmake.org/download/
2. Download MinGW-w64: https://www.mingw-w64.org/ or MSYS2: https://www.msys2.org/

### Step 3: Build (5 minutes)
Open PowerShell in the project directory:

```powershell
# Create build directory
mkdir build
cd build

# Configure
cmake -G "MinGW Makefiles" ..

# Build
cmake --build .

# Run
.\MazeGame.exe
```

### Step 4: Play!
- Press ENTER to start
- W/A/S/D to move
- Mouse to look around
- Find the red exit marker!

## TROUBLESHOOTING

**Build fails with "cannot find GLFW"**
→ Follow LIBRARIES_SETUP.txt to download and place libraries correctly

**Build fails with "cannot find glad.c"**
→ Copy glad.c from GLAD download to src/glad.c

**Runtime: "missing DLL"**
→ Copy glfw3.dll to same folder as MazeGame.exe

**Black screen when running**
→ Update graphics drivers, ensure OpenGL 3.3 support

For more help, see `docs/BUILD.txt` and `docs/README.txt`
